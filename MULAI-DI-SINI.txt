HC PORTAL - SERVER LINUX KANTOR DENGAN PODMAN

Target terbaru: Linux server. Baca deploy\linux\README.md untuk permintaan IT,
setup Podman, AD/OU, HTTPS, backup dan uji penerimaan.
Launcher .bat Windows lama sudah dihapus.

Ringkasnya:
1. Minta tim server menyiapkan VM Linux, Podman rootless, HTTPS dan jaringan.
2. Minta tim AD menyiapkan LDAPS, CA publik, akun layanan, OU dan group uji.
3. Di laptop Windows, buat paket dengan:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\windows\package-office.ps1 -Destination D:\kirim-ke-kantor
   Salin ZIP ke Linux, cek SHA-256, lalu load.
4. Isi .env.production.local dan certs/corp-root-ca.pem di Linux.
5. Jalankan Podman Compose, uji Status sistem, approval dan akun dummy.
6. Uji startup setelah reboot, backup/restore, baru minta izin OU produksi.

Panduan operasional: deploy\linux\README.md
Panduan AD dan OU: PANDUAN-AD-OU.md
Password/kunci dalam .env tidak boleh dikirim lewat chat atau di-commit.
